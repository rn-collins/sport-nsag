# SPORT Athlete Governance Workbench

A local-first workbench for athlete-centered scheduling, recovery, safeguarding, environment, voice, escalation, and governance roadmaps.

**Live:** https://sport-nsag.vercel.app

## Repository contents

`index.html`, `privacy.html`, `robots.txt`, `sitemap.xml`, `terms.html`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
